Live Portuguese TV & radio, in the browser.

A sleek, self-hosted player for twelve Portuguese TV channels and twenty radio stations: the RTP family, TVI, CNN Portugal, SIC, TSF and Rádio Comercial. One Docker stack, runs on Windows, macOS, Linux, and any device with a browser.

What it does

Everything you need to tune in

Built to be resilient: the channel list is data, playback falls back gracefully, and a small proxy handles the headers browsers can't set.

📺

Live TV

Twelve channels: RTP 1, 2 and 3, Açores, Madeira, Mundo, Memória and África, plus TVI, CNN Portugal, SIC and SIC Notícias. The last five carry a PT badge.

📻

Radio

Twenty stations: Antena 1, 2 and 3, the Açores and Madeira relays, RTP Mundo and África Rádio, Lusitânia, Fado, Jazzin, Ópera, Zig Zag and RTP Vida, plus Rádio Comercial, M80, Smooth FM, Cidade FM, Rádio Observador and TSF.

🔀

“Canais só-PT” toggle

Shows or hides the six channels that expect a Portuguese connection. Each carries a PT badge, and the player explains a refusal instead of spinning.

🐳

One command

docker compose up -d --build. Nothing else to install.

📱

Responsive

Clean on desktop and phone; the channel rail becomes a swipeable strip.

🛡️

Hardened

Non-root containers, dropped capabilities, read-only FS, CSP and a host-allowlisted proxy.

⏹️

Parar / Stop

Press the red ■ Parar button (or Esc) on the player to stop the stream and go back to choosing a channel.

Get started

Run it in three steps

  1. Clone the repository
    git clone https://github.com/ciberjohn/pt-tv-tuner.git
cd pt-tv-tuner
  2. Start the stack (requires Docker + Compose)
    docker compose up -d --build
  3. Open it in your browser
    http://localhost:8090

Change the port with WEB_PORT=9090 docker compose up -d. Add or edit channels in data/channels.json, then restart the proxy. Full details in the repository README.

Responsible use

It's a player, not a broadcaster

This project doesn't host or store any media. It streams from publicly reachable broadcaster endpoints with the requests those endpoints expect. The content belongs to the broadcasters and their terms apply. Use it for personal viewing, and don't run it as a public relay. See the README for the full note.
