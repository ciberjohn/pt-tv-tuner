A sleek, self-hosted player for RTP channels, TVI, CNN Portugal and the RTP radio family. One Docker stack, runs on Windows, macOS, Linux — and any device with a browser.

What it does

Everything you need to tune in

Built to be resilient: the channel list is data, playback falls back gracefully, and a small proxy handles the headers browsers can't set.

📺

Live TV

RTP 1, RTP 3, RTP Açores, RTP Madeira, RTP Mundo, TVI and CNN Portugal.

📻

RTP radio

Antena 1/2/3, the regional stations, Lusitânia, Fado, Jazzin, Ópera and Zig Zag.

🔀

“Canais só-PT” toggle

Reveals channels limited to Portuguese connections, with a clear explanation when egress isn't in PT.

🐳

One command

docker compose up -d --build — nothing else to install.

📱

Responsive

Clean on desktop and phone; the channel rail becomes a swipeable strip.

🛡️

Hardened

Get started

Run it in three steps

  1. Clone the repository
    git clone https://github.com/ciberjohn/pt-tv-tuner.git
cd pt-tv-tuner
  2. Start the stack (requires Docker + Compose)
    docker compose up -d --build
  3. Open it in your browser
    http://localhost:8090

Change the port with WEB_PORT=9090 docker compose up -d. Add or edit channels in data/channels.json, then restart the proxy. Full details in the repository README.

Responsible use

It's a player, not a broadcaster

This project doesn't host or store any media. It streams from publicly reachable broadcaster endpoints, the same way a browser or media player does. The content belongs to the broadcasters and their terms apply — use it for personal viewing, and don't run it as a public relay. See the README for the full note.
